## About the Project  
WebStudio is a responsive landing page for a creative web agency. The layout highlights services, portfolio, pricing, and contact information. The design prioritizes accessibility, clarity, and adaptability across devices.

## Technologies Used  
HTML5  
CSS3 (Flexbox, Grid)  
JavaScript (ES6+)  
Git & GitHub (version control)  
Responsive design principles  
Figma (design reference)

## Features  
- Hero section with navigation  
- Services overview with icons and descriptions  
- Portfolio gallery showcasing projects  
- Pricing section  
- Contact form with validation  
- Responsive layout for mobile, tablet, and desktop viewports
